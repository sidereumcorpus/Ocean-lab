How alignment works

A single line corrects wavelength offset only, not spacing or curvature. Intensities and detector pixels stay unchanged. The reference uses factory wavelengths and is not automatically saved to a dataset.

Profiles require matching serial number, source, readout size and factory grid. Demo profiles cannot align hardware. Changes apply to new captures only; saved data and device EEPROM are kept. Fractional peak digits do not indicate absolute accuracy.

Jaz defaults to channel 0. Other models ignore this field. Only one Jaz channel is acquired per connection.

Device not found?

For an Ocean Optics USB4000 or Jaz, Windows must use WinUSB to connect through this app.

  1. Connect the spectrometer directly to your computer and close OceanView, SpectraSuite, and other tabs using it.
  2. Open Windows Device Manager → spectrometer → Properties → Details → Hardware Ids. Confirm VID_2457 and PID_1022 (USB4000) or PID_2000 (Jaz).
  3. Download Zadig from its official website and run it as administrator.
  4. Select Options → List All Devices, choose your Ocean Optics spectrometer, and verify USB ID 2457 1022 (USB4000) or 2457 2000 (Jaz).
  5. Choose WinUSB as the target driver, then Install Driver or Replace Driver. Change only the selected spectrometer's driver.
  6. Unplug and reconnect it. Open this page in Chrome or Edge, leave the profile on Auto, then click Connect USB.

Changing this driver can affect Ocean Optics desktop software on this computer. It does not change the instrument or another computer.

USB disconnects when bumped?

Try a snug-fitting USB cable, remove strain from the connector and secure the cable to the bench with a loose service loop. If a known-good cable still drops out when the socket moves, have the connector inspected.

Ocean Lab preserves the last frame and attempts to reconnect to the same previously selected device. Live acquisition and recording stay paused after recovery. Retake dark/reference spectra. Disconnect cancels recovery; Retry USB retries without reopening the device chooser when identity can be verified.

Jaz reports no spectrometers?

Wait until Jaz finishes booting and shows its menu screen, then connect. If power-cycling, wait 10–15 seconds before powering it back on. A stack with additional modules may need the approved Jaz external power supply. Close OceanView and other tabs using the instrument.

The app retries a zero module count for a short startup window. If it still fails, copy the exact count or error from Session activity.

Still having trouble?
  • Use the HTTPS page, not a downloaded file opened with file://.
  • Try another USB cable or port. Check Device Manager for an error code.
  • If claiming the interface fails, close other software using the device, reconnect, and try again.
  • WinUSB and the matching legacy profile are required for USB4000/Jaz. OBP fields cannot configure these instruments.
