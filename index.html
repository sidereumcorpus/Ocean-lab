Device not found?

For your Ocean Optics USB4000, Windows must use WinUSB to connect through this app.

  1. Connect the USB4000 directly to your computer and close OceanView, SpectraSuite, and other tabs using it.
  2. Open Windows Device Manager → USB4000 → Properties → Details → Hardware Ids. Confirm VID_2457 & PID_1022.
  3. Download Zadig from its official website and run it as administrator.
  4. Select Options → List All Devices, choose Ocean Optics USB4000, and verify USB ID 2457 1022.
  5. Choose WinUSB as the target driver, then Install Driver or Replace Driver. Change only the USB4000's driver.
  6. Unplug and reconnect it. Open this page in Chrome or Edge, leave the profile on Auto, then click Connect USB.

Changing this driver can affect Ocean Optics desktop software on this computer. It does not change the instrument or another computer.

Still having trouble?
  • Use the HTTPS page, not a downloaded file opened with file://.
  • Try another USB cable or port. Check Device Manager for an error code.
  • If claiming the interface fails, close other software using the device, reconnect, and try again.
  • WinUSB and the USB4000 legacy profile are both required. OBP command fields cannot configure a USB4000.
